# Homework-1

Программа с меню на Node.js: билетная касса, доставка заказа, лестница.

## Функционал

- **1 — Билетная касса**. Вводи категорию билета (1–3) и бюджет. Программа посчитает, сколько билетов можно купить (через цикл `while`, без деления).
- **2 — Доставка заказа**. Вводи расстояние (км) и сумму заказа (руб.). Программа рассчитает стоимость доставки по условиям задания.
- **3 — Лестница**. Вводи высоту (число ступеней). Программа выведет номера ступеней от 1 до высоты: 4‑ю ступень пропускает (`continue`), после 10‑й останавливается (`break`) и показывает, сколько всего построено.

## Особенности реализации

- Используются конструкции: `if`, `while`, `for`, `continue`, `break`.
- Расчётные функции возвращают значения, вывод текста — отдельные функции.
- При вводе пункта меню, которого нет (не 1, 2, 3), выводится: `такой задачи нет`.

## Требования

- Node.js (современная версия).
- Дополнительные пакеты не нужны.
